# 🚀 Quick Start: GitHub Setup (5 Minutes)

Follow these simple steps to access your grocery app from any computer.

## Step 1: Install GitHub Desktop (2 minutes)

1. Go to: **https://desktop.github.com**
2. Click "Download for Mac" (or Windows)
3. Open the downloaded file and install
4. Open GitHub Desktop

## Step 2: Create GitHub Account (2 minutes)

If you don't have a GitHub account:
1. In GitHub Desktop, click "Create your free account"
2. Or go to: **https://github.com/signup**
3. Enter your email and create a password
4. Verify your email

## Step 3: Sign In (30 seconds)

1. In GitHub Desktop, click "Sign in to GitHub.com"
2. Enter your GitHub username and password
3. Click "Sign in"

## Step 4: Publish Your Project (1 minute)

1. In GitHub Desktop, click **"File"** → **"Add Local Repository"**
2. Click **"Choose..."**
3. Navigate to your Desktop
4. Select the **"wholefood-senior-order"** folder
5. Click **"Add Repository"**
6. Click **"Publish repository"** (big blue button)
7. Choose:
   - ✅ Keep private (recommended) - only you can see it
   - OR ⬜ Public - anyone can see it
8. Click **"Publish Repository"**

**Done!** Your project is now on GitHub! 🎉

---

## 📱 Access from Another Computer

### First Time Setup on New Computer:

1. Install GitHub Desktop on the new computer
2. Sign in with your GitHub account
3. Click **"File"** → **"Clone Repository"**
4. Find **"wholefood-senior-order"** in the list
5. Choose where to save it (e.g., Desktop)
6. Click **"Clone"**

**That's it!** Open `index.html` and start using the app.

---

## 🔄 Keeping Computers in Sync

### After Making Changes on Computer 1:

1. Open GitHub Desktop
2. You'll see your changes listed on the left
3. In the bottom-left:
   - Type a summary: "Updated shopping list"
   - Click **"Commit to main"**
4. Click **"Push origin"** (top right)

**Your changes are now saved to GitHub!**

### Getting Updates on Computer 2:

1. Open GitHub Desktop
2. Click **"Fetch origin"** (top right)
3. If there are updates, click **"Pull origin"**

**Your files are now up to date!**

---

## 💡 Simple Rules

1. **Always "Push" after making changes** (Computer 1)
2. **Always "Pull" before starting work** (Computer 2)
3. **Commit often** - save your work frequently

## 🆘 Common Issues

### "Repository not found"
- Make sure you're signed in to the same GitHub account
- Check you clicked "Publish repository"

### "Can't push"
- Make sure you're connected to the internet
- Try clicking "Fetch origin" first

### "Merge conflicts"
- This happens if you edited the same file on both computers
- GitHub Desktop will help you resolve it
- Or: save your changes, delete the file, pull again, then re-apply changes
